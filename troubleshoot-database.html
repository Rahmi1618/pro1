🔧 PharmaCare Database Troubleshooting Guide

If users are not appearing in the database after registration, follow these steps to diagnose and fix the issue.

📋 Step 1: Check XAMPP Status

Verify XAMPP Services

Make sure both Apache and MySQL are running in XAMPP Control Panel:

  • Open XAMPP Control Panel
  • Check that Apache shows "Running" (green)
  • Check that MySQL shows "Running" (green)
  • If not running, click "Start" for each service

🗄️ Step 2: Check Database Setup

Verify Database Exists

Check if the pharmacare database exists:

  1. Open phpMyAdmin
  2. Look for pharmacare database in the left sidebar
  3. If it doesn't exist, create it:
    1. Click "New" in phpMyAdmin 2. Enter database name: pharmacare 3. Click "Create"

Import Database Schema

If the database exists but tables are missing:

  1. Click on pharmacare database
  2. Click "Import" tab
  3. Choose file: backend/database.sql
  4. Click "Go" to import

🚨 Common Issues & Solutions

Issue: "Database connection failed"

Solutions:

  • Make sure MySQL is running in XAMPP
  • Check if port 3306 is available
  • Verify database credentials in backend/config/database.php

Issue: "Table 'pharmacare.users' doesn't exist"

Solutions:

  • Import the database schema: backend/database.sql
  • Make sure you selected the correct database in phpMyAdmin
  • Check if the SQL import completed without errors

Issue: "Registration appears successful but no data in database"

Solutions:

  • Check PHP error logs in XAMPP
  • Verify the API endpoint URL is correct
  • Test with the debug registration API
  • Check if transactions are being rolled back due to errors

Issue: "CORS errors in browser console"

Solutions:

  • Make sure you're accessing via http://localhost
  • Don't open HTML files directly (file:// protocol)
  • Check that CORS headers are set in PHP files
